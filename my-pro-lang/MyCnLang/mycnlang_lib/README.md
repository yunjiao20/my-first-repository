# MyCnLang lib

提供了一些模块，以拓展功能、方便使用

### string.mcl （2026/10/28添加）
字符串操作和信息处理
  - `ord/码点`： 获取单个字符的 utf-8 码点（2026/10/28添加）
  - `chr/译码`： 将码点（一个整型）译为其对应的字符（2026/10/28添加）
  - `printn/输出n`： 输出多个参数，但结尾没有换行（2026/10/28添加）
  - `split/字符串分割`： 按指定的字符分隔字符串，返回一个列表，包含各个部分（python str.split()）（2026/10/28添加）
  - `s_replace/字符串替换`： 将字符串中的子字符串替换为另一个（python str.replace()）（2026/10/28添加）

### file.mcl （2026/10/28添加）
文件操作
  - `file_read/文件读取`: 读取文件内容，返回字符串（2026/10/28添加）
  - `file_readlines/文件按行读取`: 读取文件内容，反应一个包含文件每一行的列表（2026/10/28添加）
  - `file_write/文件写入`: 文件创建和写入（2026/10/28添加）
  - `file_append/文件追加`： 文件追加（2026/10/28添加）
